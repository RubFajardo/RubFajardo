##  Mis Proyectos Destacados

### [Bank Microservices Project](https://github.com/RubFajardo/Bank-Microservices-Project)
- Este proyecto en desarrollo consiste en un sistema de microservicios distribuido diseñado para simular una infraestructura bancaria moderna. Se centra en escalabilidad, resiliencia y comunicación asíncrona basada en eventos.
- Tecnologías usadas: Java Spring Boot 3.4, RabbitMQ, Docker & Docker Compose, H2 Database y Spring Security & JWT

### [Rade](https://github.com/RubFajardo/Rade)
- Página web para el seguimiento de entrenamientos de fuerza, dieta y descanso.
- Tecnologías usadas: Angular, Tailwind CSS, RxJS y desarrollo Backend con Java Spring Boot, conectado a una base de datos PostgreSQL.

### [Habits Tracker](https://github.com/RubFajardo/Habits-Tracker)
- Página web creada para el seguimiento de hábitos saludables, incluyendo los tres pilares de una vida saludable: Sueño, alimentación y ejercicio.
- Tecnologías usadas: React y Bootstrap. Desarrollo Back-End con Python Flask y base de datos con PostgreSQL.
- Características destacadas: Login seguro, CRUD completo, conexión Front y Back con APIs RESTful
